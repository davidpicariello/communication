# HTML Presentation Builder

A dependency-free Python tool for creating self-contained HTML slide decks from JSON source files.

## Quick start

```sh
python3 scripts/create.py presentation.json
```

Create a temporary JSON source file containing a title, optional theme and size, and slides identified by layout name and field values. The generated HTML embeds the source JSON in a non-executable `application/json` script element, safely escaping `<` characters so decks can be edited and regenerated later. Delete the temporary JSON after successful generation; use `scripts/extract_source.py` to recover it into a randomly named file when you need to revise the deck.

```json
{
  "title": "Cats vs. Dogs",
  "theme": "clean",
  "size": "widescreen",
  "slides": [
    {
      "layout": "title",
      "values": {
        "title": "Cats vs. Dogs",
        "subtitle": "Two beloved companions",
        "presenter": "A quick comparison"
      }
    }
  ]
}
```

Generate the deck with `python3 scripts/create.py presentation.json -o presentation.html`. Layout names and fields are listed in `templates/index.html`. Bullet fields take arrays of strings; image fields take local image paths, which are embedded into the finished deck.

To restore the embedded JSON for edits, run `python3 scripts/extract_source.py presentation.html`. The script prints the path to the randomly named JSON file it creates. Edit the file, regenerate the presentation with `scripts/create.py`, and delete the temporary JSON when finished.

Generated decks work offline and include keyboard navigation. Use the arrow keys, Page Up/Page Down, Home, or End to navigate.

## Layout gallery

Generate or refresh the local gallery with:

```sh
python3 scripts/gallery.py
```

Open `templates/index.html` in a browser to see the available layouts and their fields.

## Project structure

- `templates/` — one HTML file per slide layout; `index.html` is generated by the gallery script.
- `styles/` — shared CSS, themes, and slide sizes.
- `scripts/create.py` — JSON-driven deck generator.
- `scripts/extract_source.py` — extracts embedded source JSON to a random filename for editing.
- `scripts/gallery.py` — offline template gallery generator.
- `skills/html-presentations/SKILL.md` — shared agent instructions.
- `.opencode/skills/html-presentations/SKILL.md` — OpenCode entry point referencing the shared skill.
